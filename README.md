# Procurement Spend & Supplier Performance Dashboard

## 📊 Project Overview

An interactive Excel dashboard designed to analyze procurement spending, supplier performance, savings, quality, delivery, and order compliance.

The dashboard transforms procurement data into business insights for monitoring supplier performance and procurement efficiency.
